Units are inferred from the wake command the library sends (±16 g at 2,048 per g, ±2,000 °/s at 16.4 per °/s, 52 Hz). At rest the accelerometer reads about 1 g, which matches.

The packet carries the gyroscope first and the accelerometer second. TrikiPy labels them the other way round; this dashboard uses the corrected order. Yaw comes from the gyroscope only, so it drifts slowly. Use Recenter to zero it.
